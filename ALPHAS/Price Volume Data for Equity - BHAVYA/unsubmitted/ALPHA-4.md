# Alpha Strategy Documentation

## Alpha Expression

```text
group_neutralize(
    rank(
        reverse(
            divide(
                subtract(close,vwap),
                multiply(vwap,adv20)
            )
        )
    ),
    industry
)
```

## Strategy Description

### Idea

This alpha exploits relative deviations between the closing price and VWAP, assuming that securities closing substantially away from their transaction-weighted fair value are temporarily mispriced and likely to revert. It targets short-term inefficiencies generated by transient order imbalances while suppressing industry-wide systematic effects.

### Rationale for Data Used

The strategy uses `close` and `vwap` to quantify end-of-day price dislocations relative to the market's average execution price. `adv20` provides a liquidity normalization baseline that reduces the influence of structurally high-turnover securities. Industry classifications are incorporated to isolate idiosyncratic mispricing from broader sector-driven movements.

### Rationale for Operators Used

- `subtract(close, vwap)` measures the magnitude of the price deviation from fair value.
- `multiply(vwap, adv20)` creates a normalization factor using both price level and average liquidity.
- `divide(...)` scales the deviation to improve comparability across securities.
- `reverse()` converts extreme positive dislocations into contrarian exposures.
- `rank()` standardizes the signal cross-sectionally.
- `group_neutralize(..., industry)` removes persistent industry biases to enhance stock-specific alpha extraction.

## Alpha Construction Pipeline

1. Compute the difference between the closing price and VWAP using `subtract(close, vwap)`.
2. Calculate a normalization factor using `multiply(vwap, adv20)`.
3. Scale the price deviation by dividing it by the normalization factor.
4. Apply `reverse()` to construct a contrarian signal.
5. Rank the resulting values cross-sectionally using `rank()`.
6. Neutralize the ranked signal by industry using `group_neutralize(..., industry)` to remove systematic effects.

## Targeted Market Inefficiency

- Short-term mean reversion following temporary price dislocations.
- Order imbalance effects that push closing prices away from transaction-weighted fair values.
- Cross-sectional mispricing among securities with different liquidity profiles.
- Persistent industry-level biases that can obscure stock-specific opportunities.
- Temporary deviations caused by end-of-day trading pressure.
